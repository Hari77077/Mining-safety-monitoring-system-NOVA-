# Mining Safety Monitoring System (NOVA) ⚒️

A comprehensive IoT-based safety monitoring system for mining environments, featuring real-time data visualization, AI-driven risk prediction, and a hybrid chatbot assistant.

##  Key Features
-   **Real-time Monitoring:** Temperature, Humidity, CO, CH4, Vibration.
-   **AI Risk Analysis:** 
    -   *Wet Bulb Prediction* (Random Forest)
    -   *Explosion Risk Assessment* (XGBoost)
    -   *Safety Score* (Neural Network)
-   **Hybrid Chatbot:** Context-aware assistance using Llama 3.2 (Local) and Gemini Pro (Cloud).
-   **Interactive Dashboard:** Multi-page UI with live charts and 3D alerts.
